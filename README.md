Dashboard de Monitoreo IoT en Tiempo Real
Sistema de monitoreo web interactivo diseñado para la visualización en tiempo real e histórica de telemetría IoT desde ThingsBoard. La plataforma permite supervisar el estado de dispositivos, evaluar niveles de gravedad de eventos y analizar patrones de respuesta e indicadores clave mediante un diseño moderno y responsivo.

Características Principales
Visualización en Tiempo Real: Conexión vía WebSockets con ThingsBoard para recibir actualización continua de telemetría, batería y estado del dispositivo.

Análisis Histórico Integrado: Representación gráfica e inmediata de evaluaciones pasadas y tendencias de síntomas mediante componentes dinámicos.

Simulación de Escenarios: Soporte para la validación de entornos de operación normal, alertas aisladas y pruebas de estrés/crisis.

Interfaz Moderna: Diseño optimizado en modo oscuro (Dark Mode) con acentos en cyan, componentes tipo Glassmorphism y navegación responsiva.

Tecnologías Utilizadas
Frontend: React, TypeScript, Vite, Tailwind CSS.

Backend / IoT Platform: ThingsBoard Cloud (MQTT / WebSockets).

Simulación: Python (Requests / MQTT Client).
